# Legacy-скрипты (формат .md)

Проект перешёл на **JSON v1.0** как source of truth. Эти утилиты нужны только если остались старые `.md` вне `data/transcripts/old/`.

| Скрипт | Назначение |
|--------|------------|
| `normalize_md.py` | Привести .md к старой канонической структуре |
| — | Для миграции в JSON используйте **`scripts/migrate_md_to_json.py`** |
