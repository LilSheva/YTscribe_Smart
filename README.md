# YTscribe_Smart
Бот ТГ для получения видео/аудио/информации о видео с разных площадок, их обработки с OmniRoute через бесплатных провайдеров для составления взаимодействия с информацией из полученного на вход контента (саммери, умное предложение возможных действий с информацией из видео). Сохранение идет на Google Drive. Также поддерживается векторизация.
