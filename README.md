# YTscribe_Smart

**YTS_bot** — это мощный локальный Telegram-бот для парсинга, скачивания медиа, умной транскрибации и семантического анализа видео. Разработан для запуска на домашнем сервере/ПК, обеспечивает приватность данных и бесплатную интеграцию с мощными AI-инструментами.

## 🌟 Основные возможности
- **Быстрый парсинг и загрузка** видео/аудио с YouTube и других платформ (через `yt-dlp`).
- **Транскрибация (Speech-to-Text)** с использованием Groq Whisper API.
- **Умная обработка контента** (Claude 3.5 / Haiku через Omniroute): генерация саммари, выделение экшен-поинтов, научный разбор.
- **Единая база знаний** (ChromaDB) на Google Диск: сохранение транскриптов и семантический поиск по истории просмотров.
- **Модульная архитектура (Feature Toggles):** любой модуль можно отключить "на лету", если API недоступно или идет отладка.

---

## 🛠 Требования (Prerequisites)
Поскольку бот работает локально и обрабатывает медиа, на хост-машине (ПК) должны быть установлены:
1. **Python 3.11** или выше.
2. **FFmpeg** — обязателен для работы `yt-dlp` и нарезки аудио (нужно добавить в PATH системы).
3. **Google Chrome** (или другой браузер) — для извлечения cookies во избежание банов от YouTube.
